Given     The base prompt, generated into the vault as Base.md, guides every [[agent]] under the shared workspace. Which folders count as the shared workspace decides which sessions load it, and so where [[rules-not-landing]] is fixed or not.
Decide    Which sessions should load the base prompt?

Where A:  Where an [[agent]] works in any folder under Documents\Projects, the [[agent]] loads Base.md, through a CLAUDE.md in Documents\Projects.
          → every project folder gets it, your work folders there too · sessions with no folder do not
Where B:  Where an [[agent]] works in any folder under Documents\Projects\personal, the [[agent]] loads Base.md, through a CLAUDE.md in that folder.
          → only your personal projects get it · work folders and sessions with no folder do not
Where C:  When any Claude Code session starts on this machine, the [[agent]] loads Base.md, through your user CLAUDE.md.
          → every session gets it, including ones with no folder · it also reaches work you may want kept apart
Combines  exclusive
Recommend A: Documents\Projects holds all your projects, so it matches the shared workspace most closely.

Decision  A
