Given     Six [[term|terms]] came from drafts now in the Archive: [[evidence]], [[finding]], [[message]], [[result]], [[verdict]] and [[verifier]]. No [[rule]] in force uses them, yet the base prompt lists every [[term]], which is [[long-replies]] in the prompt itself.
Decide    Should the base prompt leave out [[term|terms]] that no [[rule]] in force uses?

Where A:  Where a [[term]] is used by no [[rule]] in force, the decision-cards mod shall keep it out of the base prompt and list it in Docs only.
          → the base prompt drops the six [[term|terms]] and adds each back once a [[rule]] uses it · the notes stay in the vault
Where B:  Where a [[term]] is used by no [[rule]] in force, the [[agent]] shall move its note to the Archive.
          → the vault holds only [[term|terms]] in use · reviving one means restoring its note
Where C:  Where a [[term]] has a note, the decision-cards mod shall put it in the base prompt.
          → nothing changes · [[agent|agents]] keep reading six definitions they never use
Combines  exclusive
Recommend A: it keeps the prompt to what [[rule|rules]] use, and the definitions stay ready for when the parked work returns.

Decision  C
