Given     [[response|Replies]] that run long are tedious to review, which is [[long-replies]], and a [[response|reply]] whose state is buried in prose is [[hard-to-judge]]. [[response|Replies]] appear in chat, where tables render and [[link|links]] work.
Decide    What shape does each [[response|reply]] you read from an [[agent]] take?

Where A:  When writing a [[response|reply]], the [[agent]] uses a two-column table of up to four labelled rows (Done, Open, Needs you, Check), each at most two sentences, in at most 8 rows.
          → you read what changed, what is left and what waits on you at a glance, and every [[link]] works · a new shape to learn
Where B:  When writing a [[response|reply]], the [[agent]] uses up to four labelled lines (Done, Open, Needs you, Check) in a code block, each at most two sentences, in at most 8 lines.
          → the labels line up as plain text · [[link|links]] in a code block do not work
Combines  exclusive
Recommend A: the same labels, and the [[link|links]] work.

Decision  A

Consequences
- When writing a [[response|reply]], the [[agent]] puts everything in the table, with no text before or after it, and never puts the table in a code block ([[Draft-0037]]).
- When writing a [[response|reply]], the [[agent]] opens each row with its fixed words: Done with Added, Changed, Fixed, Removed or Found; Open with "… is not started, not done or blocked"; Needs you with Decide, Approve or Do; and Check with Run or Open, then "→ what you should see" ([[Draft-0034]]).
- When writing the Needs you row, the [[agent]] asks you to Approve an action or Do a step, or points to a [[question]] already open in the dialog, and never asks for a decision in the row itself ([[Draft-0035]]).
- When writing a [[response|reply]], the [[agent]] repeats Done and Open as needed, one item per row, and uses Needs you and Check at most once each ([[Draft-0036]]).
- When a row needs more than two sentences, the [[agent]] moves the detail to a linked note ([[Draft-0038]]).
- When a [[response|reply]] uses a defined word, the [[agent]] writes it as a markdown [[link]] to that word's [[term]] note, every time it appears.
