Given     These guidelines are a base prompt for every [[agent]] under the shared workspace, with the Decisions panel as one part; the mod now writes that prompt to the vault as Base.md. Which folders count as the shared workspace decides which sessions load it, which is where [[rules-not-landing]] is fixed or not.
Decide    Which sessions should load the base prompt and the Decisions panel?

Where A:  Where an [[agent]] works in any folder under Documents\Projects, the [[agent]] shall load Base.md, through a CLAUDE.md in Documents\Projects, and the decision-cards mod shall run in that session.
          → every project folder gets it, your work folders there too · sessions with no folder, like this one, do not
Where B:  Where an [[agent]] works in any folder under Documents\Projects\personal, the [[agent]] shall load Base.md, through a CLAUDE.md in that folder, and the decision-cards mod shall run in that session.
          → only your personal projects get it · work folders and sessions with no folder do not
Where C:  When any Claude Code session starts on this machine, the [[agent]] shall load Base.md, through your user CLAUDE.md, and the decision-cards mod shall run in that session.
          → every session gets it, including ones with no folder · it also reaches work you may want kept apart
Combines  exclusive
Recommend A: "under the shared workspace" reads as the folder that holds all your projects, and A follows that most closely.

Decision  A
