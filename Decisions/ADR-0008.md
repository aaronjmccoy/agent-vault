Given     Two [[rule|rules]] in the base prompt give an [[agent]] nothing to do: [[ADR-0006]] leaves test pacing to each project, and [[ADR-0007]] describes how the base prompt is loaded, which the setup does for the [[agent]]. Carrying them is [[long-replies]] in the prompt itself.
Decide    Should the base prompt leave out [[rule|rules]] an [[agent]] cannot act on?

Where A:  Where a [[rule]] only records setup or leaves the choice to each project, the base prompt leaves it out, and Docs lists it.
          → [[ADR-0006]] and [[ADR-0007]] leave the base prompt and stay in force as records · a project that sets its test pace writes that as its own [[rule]]
Where B:  Where a [[rule]] is in force, the base prompt includes it.
          → the base prompt stays complete · [[agent|agents]] keep reading two [[rule|rules]] they cannot act on
Combines  exclusive
Recommend A: what an [[agent]] cannot act on is only reading; Docs keeps the record.

Decision  A
