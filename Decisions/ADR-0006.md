Given     Some [[term|terms]] are defined before any [[rule]] uses them, such as [[evidence]], [[finding]] and [[message]]. Listing every [[term]] in the base prompt makes it longer, which is [[long-replies]] in the prompt itself, but leaving them out hides words a [[person]] may still use.
Decide    What happens to a [[term]] that no [[rule]] in force uses, in the base prompt you read and in the vault?

Where A:  Where a [[term]] is used by no [[rule]] in force, the base prompt leaves it out, and Docs lists it.
          → the base prompt lists only [[term|terms]] in use · a [[person]] who uses an unlisted word finds no definition in the prompt
Where B:  Where a [[term]] is used by no [[rule]] in force, the [[agent]] moves its note to the Archive.
          → the vault holds only [[term|terms]] in use · reviving one means restoring its note
Where C:  Where a [[term]] has a note, the base prompt includes it.
          → every defined word is in the base prompt · [[agent|agents]] read definitions no [[rule]] uses yet
Combines  exclusive
Recommend A: it keeps the prompt to what [[rule|rules]] use, and the notes stay in the vault for when a [[rule]] needs them.

Decision  C
