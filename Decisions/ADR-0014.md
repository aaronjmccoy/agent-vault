Given     Two [[rule|rules]] in the base prompt give an [[agent]] nothing to do: [[ADR-0012]] leaves test pacing to each project, and [[ADR-0013]] describes how the base prompt is loaded, which the setup does for the [[agent]]. Carrying them is [[long-prompt]].
Decide    Should the base prompt leave out [[rule|rules]] an [[agent]] cannot act on?

Where A:  Where a [[rule]] only records setup or leaves the choice to each project, the base prompt leaves it out, and Docs lists it.
          → [[ADR-0012]] and [[ADR-0013]] leave the base prompt and stay in force as records · a project that sets its test pace writes that as its own [[rule]]
Where B:  Where a [[rule]] is in force, the base prompt includes it.
          → the base prompt stays complete · [[agent|agents]] keep reading two [[rule|rules]] they cannot act on
Combines  exclusive
Recommend B: the base prompt and the cheat sheet are meant to be the same standard, and the extra words are a small price for that.

Consequences
- Where a [[rule]] is in force, the base prompt includes it, and no [[adr|ADR]] is marked as a record ([[ADR-0014-v2]]).

Decision  B
