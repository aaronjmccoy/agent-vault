Given     The base prompt, generated into the vault as Base.md, guides every [[agent]] in a workspace. Which folders count as workspaces decides which sessions load it, and so where [[rules-not-landing]] is fixed or not.
Decide    Which sessions should load the base prompt?

Where A:  Where an [[agent]] works in any folder under a workspace listed in AGENT_WORKSPACES, the [[agent]] loads the base prompt through the CLAUDE.md at that workspace's root.
          → every project under a listed folder gets it, and you choose the folders · a session outside every listed folder does not
Where B:  Where an [[agent]] works in any folder under the vault's own folder, the [[agent]] loads the base prompt through a CLAUDE.md there.
          → nothing to configure · projects outside the vault never get it
Where C:  When any Claude Code session starts on this machine, the [[agent]] loads the base prompt through your user CLAUDE.md.
          → every session gets it, including ones with no folder · it also reaches work you may want kept apart
Combines  exclusive
Recommend A: you decide which folders hold work that follows these rules.

Consequences
- If AGENT_WORKSPACES is not set, the [[agent]] writes the base prompt into no workspace, and its first [[response|reply]] in a session asks you to Do the step of setting it ([[ADR-0013-v3]]).
- Where a workspace is listed, the [[agent]] writes the base prompt into an `AGENTS.md` at that workspace's root as well as its CLAUDE.md ([[ADR-0013-v4]]).

Decision  A
