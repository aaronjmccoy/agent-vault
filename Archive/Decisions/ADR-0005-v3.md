Given     [[ADR-0005]] puts a project's layer "inside that project's repository", the cheat sheet says "at its root", and the setup looks only in the folder a session starts in. A session started in a subfolder then misses the project's [[rule|rules]], which is [[rules-not-landing]].
Decide    Where does a project's own layer sit, so that every session in that project reads it?

Where A:  Where a project has its own layer, the [[agent]] keeps it in a vault folder at the repository's root, and a session started in any folder of that repository reads it.
          → every session in the project gets the same [[rule|rules]] · the setup must find the repository's root
Where B:  Where a project has its own layer, the [[agent]] keeps it in a vault folder in the folder where sessions start, and only those sessions read it.
          → nothing changes in the setup · a session started in a subfolder misses the layer
Combines  exclusive
Recommend A: the layer should follow the project, not the folder a session happens to open.

Decision  A
