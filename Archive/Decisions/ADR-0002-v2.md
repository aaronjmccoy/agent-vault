Given     Only [[ADR-0002]] says each test traces to a [[requirement]] ID or a bug ID; the base prompt, cheat sheet and [[spec]] template never mention it. A test that traces to nothing is how [[test-sprawl]] starts.
Decide    What must every test you are shown trace back to?

Where A:  When writing a test, the author traces it to a [[requirement]] ID or a bug ID.
          → bugs get tests straight away · two kinds of ID to follow
Where B:  When writing a test, the author traces it to a [[requirement]] ID, writing a new [[requirement]] first when the test covers a bug.
          → one kind of ID, and every bug becomes part of the [[spec]] · each bug fix needs a [[spec]] edit first
Combines  exclusive
Recommend B: one kind of ID keeps the [[spec]] the single list of what must hold.

Decision  B
