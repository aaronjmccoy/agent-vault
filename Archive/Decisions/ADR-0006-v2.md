Given     [[ADR-0006]] and [[ADR-0014]] call a long base prompt [[long-replies]], but that [[term]] is defined only as replies that run too long. A problem cited for something its definition does not cover is [[hard-to-judge]].
Decide    Which problem names text that runs too long for you or an [[agent]] to read?

Where A:  When text an [[agent]] writes or reads runs too long, the [[agent]] cites [[long-replies]], and its note is reworded to cover replies and the base prompt alike.
          → one problem for all long text, and the two Givens stay as they are · the name no longer fits everything it covers
Where B:  When a base prompt runs too long, the [[agent]] cites a new problem [[term]], long-prompt, and keeps [[long-replies]] for replies alone.
          → each problem keeps a precise name · one more [[term]] to learn, and two Givens change
Combines  exclusive
Recommend B: precise problem names keep each [[adr]]'s reason clear.

Decision  B
