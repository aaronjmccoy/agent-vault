Given     [[ADR-0014]] leaves [[ADR-0012]] to [[ADR-0014]] out of Base.md to keep it short, which is [[long-prompt]], but that makes the base prompt an incomplete copy of the standard, which is [[hard-to-judge]]. Together the three add about 120 words to a base prompt of about 2,000.
Decide    Does Base.md list every [[rule]] in force, including [[ADR-0012]] to [[ADR-0014]]?

Where A:  Where a [[rule]] is in force, the base prompt includes it, and no [[adr|ADR]] is marked as a record.
          → Base.md, the cheat sheet and the Decisions folder list the same [[rule|rules]] · about 120 more words in every base prompt
Where B:  Where a [[rule]] only records setup or leaves the choice to each project, the base prompt leaves it out, and Docs.md lists it.
          → Base.md stays about 120 words shorter · Base.md lists fewer [[rule|rules]] than the Decisions folder
Combines  exclusive
Recommend A: the base prompt and the cheat sheet are meant to be the same standard, and 120 words is a small price for that.

Decision  A
