Given     The cheat sheet covers every [[rule]] in force except [[ADR-0012]], so you can't learn there that each project sets when its tests run and when to [[autocommit]]. Two versions of the standard that disagree are [[hard-to-judge]].
Decide    Does the cheat sheet tell you that each project sets when its tests run and when it commits?

Where A:  Where the cheat sheet explains checks, it says that each project sets the pace at which [[ci]] runs its tests and the pace at which to [[autocommit]].
          → the cheat sheet covers every [[adr|ADR]] · one more sentence in the checks section
Where B:  Where the cheat sheet explains checks, it leaves test pace out, because [[ADR-0012]] is a record kept out of the base prompt.
          → the cheat sheet stays as short as the base prompt · you learn about test pace only from the [[adr|ADR]] itself
Combines  exclusive
Recommend A: the cheat sheet is the human-readable version of the whole standard, records included.

Decision  A
