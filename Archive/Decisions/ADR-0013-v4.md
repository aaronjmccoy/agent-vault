Given     [[ADR-0013]] names only the CLAUDE.md that Claude Code reads, so an [[agent]] in another tool, such as Codex with its `AGENTS.md`, gets the base prompt only if you add a pointer by hand. An [[agent]] without the base prompt is [[rules-not-landing]].
Decide    Do [[agent|agents]] in tools other than Claude Code get the base prompt without you editing their files?

Where A:  Where a workspace is listed, the [[agent]] writes the base prompt into an `AGENTS.md` at that workspace's root as well as its CLAUDE.md.
          → Codex and other tools that read `AGENTS.md` follow the same [[rule|rules]] with no setup · one more generated file in each workspace, overwritten at each rebuild
Where B:  Where a workspace is listed, the [[agent]] writes the base prompt only into its CLAUDE.md, and the cheat sheet tells you to point any other tool's instruction file at Base.md.
          → no files beyond the ones Claude Code reads · each other tool needs one line added by hand
Combines  exclusive
Recommend A: every [[agent]] reads the same base prompt, which is the point of [[ADR-0013]].

Decision  A
