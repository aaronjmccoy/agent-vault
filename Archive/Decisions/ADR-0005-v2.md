Given     [[ADR-0005]] lets a project keep its own [[rule|rules]], [[term|terms]], docs and [[job|jobs]], but the base prompt, the cheat sheet and the setup only read its [[rule|rules]] and [[term|terms]]. A layer that holds more than [[agent|agents]] read is [[rules-not-landing]].
Decide    What can a project's own layer add to what you and its [[agent|agents]] read?

Where A:  Where a project has its own layer, the [[agent]] keeps its [[rule|rules]] and [[term|terms]] there, and the base prompt in that project reads them over the shared vault.
          → everything in the layer is actually read · project docs and [[job|jobs]] live elsewhere in the repository
Where B:  Where a project has its own layer, the [[agent]] keeps its [[rule|rules]], [[term|terms]], docs and [[job|jobs]] there, and the base prompt in that project reads all four over the shared vault.
          → one place for everything the project decides and does · the setup must learn to read docs and [[job|jobs]]
Combines  exclusive
Recommend A: it matches what is read today, and docs and [[job|jobs]] already have homes in a repository.

Decision  A
