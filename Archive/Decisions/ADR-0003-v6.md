Given     The base prompt writes a chat [[link]] with the note's full path, while the cheat sheet shows a path relative to the vault, which only resolves from inside it. A [[link]] that does not open leaves a word [[hard-to-judge]].
Decide    What path does a [[link]] in a chat [[response|reply]] you read point to?

Where A:  When writing a [[response|reply]], the [[agent]] writes each [[link]] as a markdown [[link]] to the [[term]] note's full path on this machine.
          → every [[link]] opens, from any project · paths differ from machine to machine
Where B:  When writing a [[response|reply]], the [[agent]] writes each [[link]] as a markdown [[link]] to the [[term]] note's page in the published repository.
          → the same [[link]] works on any machine · it opens the published version, which can lag your local edits
Combines  exclusive
Recommend A: it always opens the notes you are actually working with.

Decision  A
