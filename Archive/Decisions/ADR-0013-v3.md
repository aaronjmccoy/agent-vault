Given     [[ADR-0013]] says the workspaces are the folders listed in AGENT_WORKSPACES, but where it is not set, the base prompt is written to folders that came preset with this vault, which on another machine are wrong. A setup that works only on its author's machine makes [[rules-not-landing]] for anyone who adopts it.
Decide    Which sessions load the base prompt on a machine where AGENT_WORKSPACES is not set?

Where A:  If AGENT_WORKSPACES is not set, the [[agent]] writes the base prompt into no workspace, and its first [[response|reply]] in a session asks you to Do the step of setting it.
          → nothing is written to a folder you didn't choose · until it is set, no session outside the vault loads the base prompt
Where B:  If AGENT_WORKSPACES is not set, the [[agent]] treats the folder that holds the vault as the one workspace and writes the base prompt into a CLAUDE.md there.
          → works with no setup when the vault sits beside your projects · a vault cloned somewhere else puts the prompt over an unrelated folder
Combines  exclusive
Recommend A: you choose every folder the base prompt reaches, as [[ADR-0013]] already decided.

Decision  A
