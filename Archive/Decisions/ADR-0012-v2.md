Given     [[ADR-0012]] lets each project set the pace at which [[ci]] runs its tests, but the [[ci]] [[term]] says it runs tests whenever code is committed. A [[term]] that disagrees with its [[rule]] is [[hard-to-judge]].
Decide    What does the [[ci]] [[term]] tell you about when your tests run?

Where A:  When defining [[ci]], the [[term]] note says it is the automated checker that runs a project's tests at the pace that project sets.
          → the [[term]] matches [[ADR-0012]] · nothing in the [[term]] says what happens in a project with no pace set
Where B:  When defining [[ci]], the [[term]] note says it is the automated checker that runs tests whenever code is committed, unless a project sets another pace.
          → commit stays the default for every project · a shared default is back, which [[ADR-0012]] chose against
Combines  exclusive
Recommend A: it says what [[ADR-0012]] decided and adds no default the decision left out.

Decision  A
