Given     The Decisions folder reads as one finished list: [[adr]] numbers run in order with no gaps, and superseded drafts sit in the Archive. An [[adr]] that amends another would otherwise leave a superseded number in the list, which makes it [[hard-to-judge]].
Decide    What happens to the Decisions list you read when an [[adr]] that amends another is decided?

Where A:  When an [[adr]] that amends another is decided, the [[agent]] moves the amended [[adr]] to the Archive, gives the decided one its place, and renumbers the [[adr|ADRs]] in force so they run in order with no gaps, updating every [[link]] to them.
          → the Decisions folder always reads as one finished list · [[link|links]] and references must be updated on each renumber
Where B:  When an [[adr]] that amends another is decided, the [[agent]] marks the amended [[adr]] superseded and leaves both in place.
          → nothing moves · the list fills with superseded numbers
Combines  exclusive
Recommend A: the Decisions folder stays one readable list, at the cost of updating [[link|links]] on each renumber.

Decision  A
